# Skill: Smart Bulk Commit & Push

## Мета

Автоматизувати процес створення логічних комітів для великої кількості змін, з обов'язковим підтвердженням користувачем перед відправкою в репозиторій.

## Алгоритм дій

### 1. Аналіз та групування

- Виконай `git diff --name-only`, щоб побачити змінені файли.
- Групуй зміни за функціональним призначенням (наприклад, окремо логіку, окремо тести, окремо документацію).

### 2. Створення комітів

- Для кожної групи змін використовуй формат **Conventional Commits** (наприклад, `feat:`, `fix:`, `refactor:`).
- Виконуй `git add` тільки для файлів конкретної групи.
- Створюй коміт локально: `git commit -m "назва_коміту"`.

### 3. Human-in-the-loop (Контроль користувача)

- **ПЕРЕД** виконанням `git push` виведи резюме:
  - Список створених комітів.
  - Назву гілки, куди вони будуть відправлені.
- Запитай: "Бажаєте відправити ці зміни у віддалену гілку? (так/ні)".

### 4. Завершення

- Якщо користувач згоден, виконай `git push origin [поточна_гілка]`.
- Якщо ні — зупинись і залиш коміти локальними для подальшого редагування.
